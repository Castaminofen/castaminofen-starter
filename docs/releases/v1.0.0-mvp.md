# Castaminofen v1.0.0-mvp

## Release Date

2026-07-26

## Executive Summary

Castaminofen v1.0.0-mvp marks the first MVP release of the podcast platform repository. This release focuses on the core product experience: authentication, podcast and episode browsing, search, library, playlist, and player-based playback with queue, repeat, and shuffle support.

## MVP Scope

This release delivers the core MVP experience for a mobile-first podcast platform:

- user authentication and protected access
- podcast and episode discovery
- search experience
- library and continue-listening flows
- playlist creation and interaction
- player runtime with queue and playback modes

## Major Implemented Features

### Authentication

The repository includes login, registration, logout, token handling, and protected-route support for the MVP experience.

### Podcast & Episode

Podcast list/detail flows and episode presentation are implemented as part of the current product surface.

### Search

Search is available through the current web application structure and routes.

### Library

Library support includes subscription-oriented and continue-listening experiences, integrated with the existing Player surface.

### Playlist

Playlist support includes CRUD-oriented flows and integration with the existing playback runtime.

### Player

The Player feature provides the primary playback runtime for the MVP. It owns queue behavior, repeat, shuffle, progress, and playback lifecycle.

## Backend Summary

The backend is organized around feature-oriented NestJS services and controllers. Prisma models and related API flows support the current MVP product surface, including authentication, podcasts, episodes, library, and playlists.

## Frontend Summary

The frontend is built with Next.js, React, TypeScript, Tailwind CSS, React Query, Zustand, and feature-based folder organization. The app shell, providers, routes, and feature surfaces are aligned with the current MVP structure.

## Player

The Player remains the single runtime owner for playback state and queue handling. Repeat and shuffle support are included in the MVP scope, and the runtime remains centralized within the Player feature.

## Queue

Queue support is included for sequential playback navigation and playback continuity. Queue interactions remain scoped to the Player runtime.

## Library

The Library experience includes key MVP flows for subscription and continue-listening behavior and integrates with the Player runtime without shifting ownership away from the Player feature.

## Playlist

Playlist support includes playlist presentation and playback integration for the MVP scope.

## Search

Search remains available in the current frontend and backend structure and is aligned with the broader MVP experience.

## Authentication

Authentication support includes the core user sign-in and account-access flow required for the first MVP release.

## Architecture Highlights

- feature-oriented frontend structure
- backend service/controller separation
- shared types and shared infrastructure
- clear Player ownership boundary for runtime behavior
- documentation-aligned phase-based delivery

## Performance Summary

The current MVP release is lightweight and structurally focused. The implementation avoids unnecessary architectural complexity while preserving the core playback and content experience.

## Accessibility Summary

The current implementation includes baseline accessibility-oriented structure and semantic UI patterns suitable for the MVP release scope.
